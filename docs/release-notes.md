# 红果桌面助手 v0.1.0

**红果短剧 Windows 11 桌面播放助手：通过 WSA（类似安卓模拟器）运行安卓 APP 安装包（APK），支持无标题栏、无边框播放及 APP 提供的 1080P 高清，工具不额外转码或压缩音视频。**

直接在电脑上运行红果安卓 APP，提供自动横竖屏、鼠标滚轮切集和观看进度保护。实际画质取决于 APP 和片源；整条播放链路的音频无损效果尚未验证。其他 APK 可以安装，播放辅助目前针对红果适配。

- 公开 Python/Flet、Java 页面读取和 C++ 窗口组件源码。
- 提供源码/成品安装入口、环境检查与 Agent 操作说明。
- 自动检测已注册 WSA，支持指定社区发行包安装。
- 将原开发机的 NDK/视频兼容修复泛化为具有哈希约束、备份和恢复的脚本。
- 保留中文操作界面、APK 拖拽、自动横竖屏、标题栏控制、滚轮切集及观看进度保护。

适用范围为 Windows 11 x64。源码运行需要 Python 3.11+；兼容修复需要 WSL 与 Linux 镜像工具。WSA/APK 不包含在助手 ZIP 中，来源和准备步骤见仓库文档。

本次发布文件的离线检查记录见 docs/validation.md。新的通用安装/修复流程尚未在第二台全新电脑完成端到端验证；实际播放仍需人工确认。
