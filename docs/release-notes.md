# 红果桌面助手 v0.1.8 · 播放与后台联动

在 Windows 11 上用独立无边框小窗看短剧，边看边办公。

- 内置独立后台守护，异常时自动恢复并接回现有播放窗口。
- 关闭助手窗口会最小化；“退出工具”或 Ctrl+Shift+Q 同时关闭助手和红果播放窗口。
- 支持手动全屏、选集、自动横竖屏、等比例缩放及滚轮切集。

**旧版用户更新完整助手即可，窗口、页面读取和守护组件已随附。WSA 与红果 APP 无需重装，账号、观看记录和设置保留。**

[复制给 Agent 的安装与更新提示词](https://github.com/xiaotu6e/hongguo-desktop/blob/main/docs/agent-prompts.md) · [使用方法](https://github.com/xiaotu6e/hongguo-desktop/blob/main/docs/usage.md)

适用于 Windows 11 x64。成品无需另装 Python，WSA 和 APK 按仓库安装说明准备。
