# 验证范围

当前版本在 Windows 11 x64、WSA 2407.40000.4.0 LTS8、红果 7.3.9.32 的开发机环境中完成验证。

- 离线测试覆盖播放控制、窗口比例、安装边界、更新计划和后台联动；Windows PowerShell 5.1 脚本解析通过。
- 实际 Windows 成品验证了最小化、重复启动、后台异常恢复、滚轮操作，以及主动退出时同时关闭播放器。
- 独立测试客户端验证了心跳超时恢复与连续失败后的停止重试、播放器关闭请求。
- 手动全屏、选集、横竖屏、窗口缩放、实际画面与声音经过本机操作检查。
- 成品版本、随附组件、发布包 SHA-256 和安装入口在发布时核对。

未完成第二台全新 Windows 电脑的完整安装验收；其他 WSA / APK 版本需要重新验证。静态检查成功不能代替实际画面、声音与操作确认。

原始日志、截图、个人配置和观看数据保存在本地。
