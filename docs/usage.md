# 使用方法

## 启动与连接

安装后使用桌面或开始菜单的 Hongguo Desktop Helper 快捷方式。工具连接已注册的 WSA；首次安卓冷启动需要等待。连接地址默认 127.0.0.1:58526，首次需在 WSA 设置中开启开发人员模式并允许 ADB。

首页可以启动/连接 WSA、选择 APK 或拖入 APK 安装。“我的应用”支持打开、关闭、设为默认和卸载应用。卸载操作会影响对应应用的数据，按界面提示操作。

## 播放辅助

播放器与管理工具是两个独立桌面窗口。无边框视频小窗可以移动到屏幕上方便观看的位置，让你一边看短剧、一边操作其他办公软件。APP 的“全屏观看”是在当前播放小窗中展开画面，默认不会把播放器铺满整个电脑屏幕。

[查看视频小窗与管理工具同屏实拍](images/small-window-and-manager.png)。

“常用设置”可以设置智能起播、本机观看进度保护、自动全屏、清晰度和标题栏。

- 默认手动点击 APP 的“全屏观看”或“清屏播放”。“自动横竖屏”只跟随 APP 的实际播放方向调整窗口，不会替你进入全屏。
- 如开启“每部剧首次进入时自动全屏 / 清屏”，同一助手会话中每部剧只在从推荐页首次进入时自动处理一次。退出全屏、返回选集、切集或重新连接后，同一部剧不会再次自动全屏；手动全屏按钮始终可用。
- 修改清晰度或在播放中开启自动全屏，不会把当前剧重新切入全屏；新的自动全屏偏好从下一部首次进入的剧开始应用。
- 自动横竖屏根据实际页面切换 16:9 或 9:16 窗口，也可以固定横屏或竖屏。
- “隐藏白色标题栏”让红果以无标题栏、无边框的窗口显示，保留完整安卓画面。画面顶部中间区域可拖动窗口。
- 鼠标靠近四条边或四个角时会变为缩放指针，按住左键拖动即可调整大小。横屏保持 16:9，竖屏保持 9:16；拖动顶部中间区域仍是移动窗口。
- 同一播放窗口按横屏 / 竖屏分别记住手动调整的尺寸，方向切回或助手重新连接后沿用。关闭播放窗口后，新窗口从默认尺寸开始。缩放不会改变 APK 的清晰度设置，也不会额外转码视频。
- 推荐页滚轮上下切换内容；播放页上下切集；选集面板滚动列表。鼠标位于其他软件时不接管滚轮。
- 智能起播只在符合推荐集数与实际进入集数的规则时回到第 1 集。本机已记录进度会受到保护。
- 清晰度使用 APK 自己提供的档位，可优先选择 1080P 或 720P；实际画质取决于 APP 和片源提供的档位，不通过拉伸伪造分辨率。

播放图像、声音、登录、节目加载与应用服务均由红果 APK 和 WSA 处理。助手只负责窗口与操作辅助，不对音视频做二次转码或压缩。工具识别的是已验证版本的界面控件；APK 升级后可能需要适配。其他 APK 可以安装，但红果专用的播放辅助不保证适用。

## 关闭与退出

助手窗口右上角的 × 会最小化，播放辅助继续工作；真正结束请选择左侧“退出工具”，或在助手获得焦点时使用 Ctrl+Shift+Q。退出会同时关闭红果播放窗口与后台守护。

已有助手运行时，再次启动会尝试恢复原窗口，不建立另一套播放辅助连接。升级时先“退出工具”，再打开新版本。

Windows 成品由独立守护程序启动。后台异常结束时会自动恢复并接回现有播放窗口，通常需要数秒；连续恢复失败时会停止重试、请求关闭播放器并提示用户。

## 网络设置

默认的“启动/连接时保持 WSA 直连”会关闭 WSA 安卓环境的显式代理，影响其中全部安卓应用。它不修改 Windows 系统代理；整机 VPN/TUN 仍可能接管流量。关闭该选项只停止自动修改，不恢复旧的安卓代理。

## 设置与日志

设置、观看记录和诊断日志位于 `%LOCALAPPDATA%\HongguoDesktopHelper`。观看记录仅包含本工具运行时识别到的剧名与集数，不能代表 APK 账号的完整云端历史。

可以从“操作记录”打开日志目录。提交问题时仅分享必要且去除个人信息的日志片段，描述 Windows/WSA/APK 版本、触发步骤和实际结果。

## 安装成功后的确认

连接成功和 APK 安装成功之后，打开应用，检查实际画面与声音，再检查连续切集、横竖屏、选集与清晰度。若启动或解码问题与已验证组合一致，参照 compatibility.md 的版本限制与修复步骤。
