# 使用方法

## 启动与连接

安装后使用桌面或开始菜单的 Hongguo Desktop Helper 快捷方式。工具连接已注册的 WSA；首次安卓冷启动需要等待。连接地址默认 127.0.0.1:58526，首次需在 WSA 设置中开启开发人员模式并允许 ADB。

首页可以启动/连接 WSA、选择 APK 或拖入 APK 安装。“我的应用”支持打开、关闭、设为默认和卸载应用。卸载操作会影响对应应用的数据，按界面提示操作。

## 播放辅助

“常用设置”可以设置智能起播、本机观看进度保护、自动全屏、清晰度和标题栏。

- 自动横竖屏根据实际页面切换 16:9 或 9:16 窗口，也可以固定横屏或竖屏。
- “隐藏白色标题栏”只控制 Windows 窗口外观，保留完整安卓画面。画面顶部中间区域可拖动窗口。
- 推荐页滚轮上下切换内容；播放页上下切集；选集面板滚动列表。鼠标位于其他软件时不接管滚轮。
- 智能起播只在符合推荐集数与实际进入集数的规则时回到第 1 集。本机已记录进度会受到保护。
- 清晰度使用 APK 自己提供的档位，不通过拉伸伪造分辨率。

播放图像、声音、登录、节目加载与应用服务均由红果 APK 和 WSA 处理。工具识别的是已验证版本的界面控件；APK 升级后可能需要适配。

## 关闭与退出

助手窗口右上角的 × 会最小化，播放辅助继续工作；真正结束请选择左侧“退出工具”，或在助手获得焦点时使用 Ctrl+Shift+Q。退出会恢复播放窗口的标准标题栏。

已有助手运行时，再次启动会尝试恢复原窗口，不建立另一套播放辅助连接。升级时先“退出工具”，再打开新版本。

## 网络设置

默认的“启动/连接时保持 WSA 直连”会关闭 WSA 安卓环境的显式代理，影响其中全部安卓应用。它不修改 Windows 系统代理；整机 VPN/TUN 仍可能接管流量。关闭该选项只停止自动修改，不恢复旧的安卓代理。

## 设置与日志

设置、观看记录和诊断日志位于 `%LOCALAPPDATA%\HongguoDesktopHelper`。观看记录仅包含本工具运行时识别到的剧名与集数，不能代表 APK 账号的完整云端历史。

可以从“操作记录”打开日志目录。提交问题时仅分享必要且去除个人信息的日志片段，描述 Windows/WSA/APK 版本、触发步骤和实际结果。

## 安装成功后的确认

连接成功和 APK 安装成功之后，打开应用，检查实际画面与声音，再检查连续切集、横竖屏、选集与清晰度。若启动或解码问题与已验证组合一致，参照 compatibility.md 的版本限制与修复步骤。
