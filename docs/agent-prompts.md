# 复制给 Agent 的安装与更新提示词

推荐使用方式是：**复制下面整段提示词，发给能操作你这台 Windows 电脑的 Agent，让它调用仓库完成安装。**不需要自己编译 Python 工具，也不需要自己逐条输入安装命令。

同一段提示词适用于 Codex、DSH（DeepSeek Harness），以及具备本机电脑操作 / PowerShell 执行能力的豆包等 Agent。关键是当前 Agent 会话能在你的 Windows 本机执行命令；只有云端聊天能力的会话需要切换到具备本机执行能力的 Agent。仓库不要求安装特定平台插件。

## 安装提示词

直接复制整个文本框，无需改仓库地址：

```text
请直接在我这台 Windows 电脑上安装“红果桌面助手”：
https://github.com/xiaotu6e/hongguo-desktop

我要用它在无标题栏、无边框的独立桌面小窗里看红果短剧，同时操作其他办公软件。请实际执行安装，完成后启动，不要只给我教程或命令清单。

1. 确认你能在这台 Windows 本机执行 PowerShell 命令，检查是否为 Windows 11 x64。下载或克隆仓库到固定目录，先读取 README.md、AGENTS.md、docs/installation.md 和 docs/agent-prompts.md。
2. 读取 manifests/release.json，使用其中的明确版本和 SHA-256，优先通过 scripts/install.ps1 的 Release 模式安装成品，省去 Python 和编译环境。先执行 -DryRun 检查计划，再完成实际安装；不要把预览当成安装成功。
3. 检查现有 WSA：已有可用环境就复用，缺少时按仓库说明使用 -InstallWsa；虚拟化未开启时使用 -EnableVirtualization。只有遇到文档中对应的启动或解码问题时，才读取 docs/compatibility.md 并执行 -RepairWsa。
4. 已安装红果 APP 时直接复用；未安装时请我提供本地红果 APK 文件路径，再用 -ApkPath 安装。仓库不包含 APK，不要随便下载来源不明的安装包。保留已有账号、应用数据和观看记录。
5. 将播放窗口设为自动横竖屏、隐藏标题栏，默认手动点击全屏按钮；这里的“全屏”是小窗内展开播放，不是铺满电脑屏幕。
6. 需要我处理管理员授权、Windows 重启、WSA 开发人员模式、ADB 授权或账号登录时，只说明当前这一步怎么做；完成后接着执行余下安装。
7. 创建桌面 / 开始菜单快捷方式，运行 scripts/doctor.ps1 -Json 检查，启动助手和红果。最后用简单中文告诉我：安装版本、快捷方式在哪、已完成哪些检查、还有没有需要我操作的一步。
```

Agent 应优先读取仓库当前清单，不依赖提示词里写死的版本。运行成功后，日常直接使用已创建的快捷方式；Agent 负责首次环境准备和后续更新。

## 更新提示词

```text
请帮我更新已经安装的“红果桌面助手”：
https://github.com/xiaotu6e/hongguo-desktop

请实际完成更新，并保留红果账号、WSA 环境、观看记录和其他设置。

1. 获取仓库当前的更新说明，先读取 AGENTS.md、CHANGELOG.md、docs/updating.md、manifests/updates.json 和 manifests/release.json。
2. 从 installation.json、实际快捷方式目标和助手版本信息确认当前安装方式与版本。运行 scripts/update-plan.ps1 -Json；旧安装没有安装记录时，核对真实版本后传入 -CurrentVersion。不要只看仓库版本就认定本机已更新。
3. 更新前先用简单中文说明：“当前版本 → 目标版本；这次改了什么；需要更新哪些组件；哪些组件无需更新；哪些数据会保留。”然后继续完成已要求的更新，无需让我再次确认普通更新步骤。
4. 如果当前已是目标成品版本，仅同步新的文档和 Agent 脚本；不要重装 WSA 或 APP。需要更新助手时，正常退出旧助手，按 docs/updating.md 安装完整新版本、更新原有快捷方式并启动。不要只覆盖单个 EXE，不要强制重置有本地修改的源码目录。
5. WSA、红果 APK、Java / C++ 组件或 Python 依赖只在对应版本更新清单明确要求时才处理。不要卸载 APP，不清除观看记录，不做无关的环境重装。
6. 从 v0.1.0 更新时，检查旧的自动全屏设置；按我希望手动控制播放的需求关闭自动全屏，保留其他设置。更新到 v0.1.1 后，退出全屏、选集、切剧和恢复连接不应再次强制当前剧全屏。
7. 更新后检查实际启动的版本和快捷方式目标，运行 scripts/doctor.ps1 -Json。最后告诉我：已更新哪些组件、保留了哪些数据，以及本次最明显的使用变化。
```

## Agent 的结果提示示例

> 当前 v0.1.0 → v0.1.1。此次更新助手完整程序，修复退出全屏后被重新切回的问题；检查并关闭旧的自动全屏设置。WSA 和红果 APP 无需重装，账号和观看记录会保留。

> 当前已是 v0.1.1。这次仓库只补充更新说明、Agent 提示词和小窗实拍图，助手成品无需重新安装。
